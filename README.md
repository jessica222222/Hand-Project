# 多人連線 AI 手勢辨識互動遊戲平台

本專題結合人工智慧影像辨識、遊戲開發與多人連線技術，製作一套以手勢操作為主的互動遊戲平台。

---

## 特色與目標

1. **建立手勢操作方式**
   * 利用 **YOLOv8** 模型辨識三種手勢：**握拳**、**讚**、**手掌**。
   * 分別對應角色的**左移**、**跳躍**與**右移**，保留**鍵盤操作**作為備用方案。

2. **完成本地端即時辨識**
   * 將訓練完成的模型轉換為 **ONNX** 格式。
   * 透過 **Unity Sentis** 直接在使用者端進行推論，不需將影像傳送至外部伺服器，確保隱私與即時性。

3. **實現多人連線**
   * 利用 **Mirror** 框架建立強大的多人遊戲架構。
   * 搭配 **Unity Relay** 支援跨網路連線，可同時讓**四名玩家**一同加入遊戲互動。

4. **設計雙手操作關卡**
   * 精心製作四大特色關卡：**上樓梯**、**下樓梯**、**排球**及 **獨木橋**。
   * 讓玩家在不同的遊戲情境與挑戰中，使用左右手完成流暢的操控體驗。

---

## 使用技術
* **遊戲引擎**：Unity 2D
* **AI 影像辨識**：YOLOv8, ONNX, Unity Sentis
* **多人連線**：Mirror, Unity Relay
